# Experimental Plan

## Research center

The completed CPA Cognitive Development Lab established a useful local developmental grammar across compute, model selection, lineage birth, influence, memory standing, relation habit, epistemic ancestry, and external consultation. Its closing handoff explicitly moved the next question outward.

This laboratory asks:

> What develops among bounded minds when they can exchange selected public evidence without collapsing their independent interiors?

## Founding constraints

The first experiments preserve these constraints unless a protocol explicitly challenges one of them:

1. causal execution is bounded and observable;
2. each mind has persistent private history;
3. inter-mind exchange crosses compact public surfaces only;
4. standing is provisional permission to influence later cognition;
5. provenance and ancestry remain distinct from surface agreement;
6. communication, verification, consultation, and storage have explicit cost;
7. no process receives unrestricted access to all private interiors;
8. protocol controls may be deliberately artificial, but they must be labeled as controls rather than promoted into architecture.

## Initial arc

### Protocol 01: local versus shared memory contamination

Can a receiver gain useful prior structure from a source without treating another history as lived consequence?

Status: **implemented, result pending**.

### Protocol 02 candidate: peer disagreement with preserved interiors

Give bounded peers different evidence about one phenomenon. Compare compact public exchange with full-state synchronization. Test whether independent error structure improves later correction even if consensus is slower.

### Protocol 03 candidate: developmental versus doctrinal transfer

Compare transfer of a final rule with transfer of selected developmental episodes or consequence history. Keep this separate from Protocol 01's narrower authority/contamination question.

### Protocol 04 candidate: bounded communication before language

Permit low-dimensional typed signals before linguistic negotiation. Test whether unresolved disagreement survives longer and whether later language reports the true shape of remaining tension.

### Protocol 05 candidate: emergent convention

Repeated interaction may produce shared coordination conventions. Persistence must be earned by consequence and remain revisable when local environments diverge.

### Later candidate: incomplete epistemic ancestry

Prior work assumed evidence-origin identity was available. A successor assay should ask whether common ancestry can be inferred when origin is absent, partial, copied, or misleading.

## Result cadence

For ordinary iteration, prefer the smallest targeted result set that can answer the current question. Protocol 01 should first run across seeds `101,211,307,401,503` after the invariant suite passes.

A full current-suite rerun becomes useful after changes to shared experiment runtime, public frame/artifact contracts, inter-mind communication infrastructure, standing semantics, or other common mechanisms that could alter older protocols. Early in this repository the targeted matrix and full suite are identical because only Protocol 01 exists.

## Explicitly deferred

- production CPA runtime design;
- final Rust implementation;
- language negotiation among peers;
- mature social identity or culture models;
- a global trust hierarchy;
- full-state synchronization as a proposed architecture;
- importing old protocol-local controllers merely to accelerate implementation.
