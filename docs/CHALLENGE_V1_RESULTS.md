# challenge-v1 Results

Status: **consumed exploratory evidence**  
Run version: **0.9.0**  
Reviewed: **2026-08-20**

`challenge-v1` searched the frozen Protocol 03-07 world-generator families using outcome-blind descriptor ranking. It was intentionally adversarial and was never a second holdout.

## Aggregate result

```text
100 challenge runs
 78 Support
 22 Mixed
  0 Disconfirm

mechanism outcome   317 / 320
safety boundary     207 / 220
manipulation         133 / 140
accounting             78 / 80
```

The challenge successfully moved the laboratory farther away from the development phase's all-Support pattern. More importantly, it exposed a limitation in the challenge design itself: the composite descriptor called `stress` was usually not a monotonic causal variable.

## Protocol 03 - source instability

Result: **18 Support / 2 Mixed**.

One extreme selected world crossed the whole-history developmental-versus-doctrinal boundary. Another high-stress world narrowly lost the unstable-history advantage while retaining whole-history benefit.

Revised conclusion:

> Developmental history is useful when its shape is informative about current transfer risk. Remembering instability is not intrinsically beneficial. Old instability can become an unnecessary discount on a final rule that is now locally useful.

The composite `source instability` score did not monotonically move the mechanism toward failure. Greater instability can make developmental context more useful, not less. Future falsification therefore separates **history instability** from **present rule error / history informativeness**.

## Protocol 04 - conflict density

Result: **19 Support / 1 Mixed**. The Mixed case was a manipulation miss. All mechanism checks passed.

Increasing the registered conflict-density score tended to strengthen, rather than weaken, the typed path. This means the profile was feeding the mechanism more of the condition it was designed to exploit.

Revised conclusion:

> Environmental conflict density is not the unresolved test. Protocol 04 now needs a stronger comparator with the same public information budget, rather than more seeds against deliberately destructive semantic smoothing.

`parameterized-falsification-v1` therefore compares the frozen typed weighted reducer with a standing-weighted robust consensus that receives the exact same estimate/standing/uncertainty packets.

## Protocol 05 - regime shift

Result: **14 Support / 6 Mixed**.

Several Mixed worlds were manipulation coverage misses, but the substantive failures sharpened the stability/plasticity tradeoff. In one high-pressure world the adaptive culture revised all changed contexts and recovered useful late utility, yet stable retention fell below the registered boundary and communication work exceeded its allowance.

Revised conclusion:

> Cultural revisability and cultural stability are opposing pressures. A convention can remain adaptive while becoming too willing to reopen stable habits or too expensive to maintain.

The frozen generator contains only one bounded regime transition. Future falsification directly controls **change frequency** and **change magnitude**, including repeated change outside the original generator support.

## Protocol 06 - ancestry visibility

Result: **17 Support / 3 Mixed**.

The central echo-discounting mechanism remained useful, but safety failures again showed that ancestry inference can reduce the value of genuinely independent convergence. Some failures occurred even when the explicit false-merge statistic was low.

Revised conclusion:

> The risk is not only categorical mis-grouping. Soft corroborative weighting under uncertain ancestry can become harmful even when obvious false merges are rare. Ancestry in CPA should remain graded dependence evidence, not hard deduplication.

The frozen generator cannot reach complete provenance blindness. Future falsification separately controls **origin missingness** and **developmental-signature separation**.

## Protocol 07 - recommender fragility

Result: **10 Support / 10 Mixed**. The extreme selected band returned 0 Support / 4 Mixed.

Two distinct failure modes appeared:

1. provisional standing can impose too much whole-history opportunity cost relative to learning alone as mismatched recommendations become common;
2. behavior can correct before social standing fully revokes, leaving excessive latent permission for a source that has become locally wrong.

The original composite fragility score mixed recommender credibility, mismatch prevalence, and mismatch magnitude, and did not produce a clean monotonic boundary.

Revised conclusion:

> Second-hand standing should buy bounded opportunity only while the receiver's own consequence can rapidly dominate it. Recommender reliability, mismatch prevalence, and mismatch severity are separate causal pressures and should be measured separately.

`parameterized-falsification-v1` therefore includes two independent P07 surfaces rather than another composite score.

## What challenge-v1 changed methodologically

The important negative result is about the challenge apparatus itself.

```text
random world
  -> several coupled descriptors
  -> one composite stress score
  -> ranked bands
```

is not a reliable way to infer a causal operating envelope when the descriptors can push a mechanism in opposite directions.

The next phase instead uses controlled interventions:

```text
frozen local mechanism
  + independent causal axis X
  + independent causal axis Y
  -> response surface
  -> crossover / null / harmful regions
```

This phase is exploratory falsification. It deliberately moves outside the original world-generator support. It does not create fresh confirmation evidence and it does not authorize tuning followed by reuse of the same surface as validation.
