# Source Reconciliation

## Sources used

The founding solution was reconciled against:

- the Project handoff summary in `SuccessorLab.md`;
- *Columnar Presence Architecture v010*;
- the completed CPA Cognitive Development Lab v1.0.0 source and documentation;
- the existing CPA project trajectory from Rust bounded execution through the .NET developmental lab.

## Carried forward

### Bounded local history

CPA's column boundary and the completed .NET lab both depend on local continuity that can return changed. The successor raises that boundary to whole experimental organisms: each mind must retain a private developmental interior.

### Public surfaces instead of full introspection

The CPA book describes disciplined public column state and warns against making every private state globally inspectable. The successor applies the same discipline across minds. The first shared trace packet is a compact public compression, not an object reference into another memory.

### Standing remains revisable

The old lab repeatedly found value in separating representation from permission to influence. Protocol 01 carries that principle across an organism boundary. A foreign trace may be remembered and useful without automatically inheriting direct authority.

### Provenance distinct from agreement

Protocol 18 of the old lab preserved evidence ancestry. The successor begins with explicit source/origin identifiers in its public trace packet. Hidden or incomplete ancestry remains a later research problem.

### Explicit cost

Communication is charged even in the first minimal assay. Cost does not determine truth. It prevents apparently successful transfer from hiding an unlimited shared-state channel.

## Deliberately not carried forward

The new core does not import the old laboratory's dormancy, birth, model-family tournament, earned-influence, coalition-habit, oracle consultation, or protocol-specific ancestry controllers.

Those mechanisms remain evidence and inspiration. They are not assumed to be the internal anatomy required for development among minds.

## Book diagrams

The book's input boundary, cognitive tick, public/private column membrane, and memory-metabolism diagrams remain useful conceptual references. They describe separation of contact, public residue, local update, and governed memory influence.

They should not be read as a requirement that the successor lab implement the book's entire engine-plane plumbing. This laboratory is intentionally synthetic and narrow.

## Desktop reference

The old Desktop Lab source was inspected for final reference. Its later `MetricChart` already used stream geometry, cached static drawing, display downsampling, bounded per-path history, binary-search-neighborhood hover, and a throttled hover timer. Its coordinator also used a bounded non-blocking channel.

The successor changes the division of labor rather than merely tuning those constants. A background projector now consumes display frames and owns telemetry aggregation. WPF no longer drains up to hundreds of experiment frames per dispatcher tick or applies each one to several controls. The graph sees sampled snapshots whose size is governed by display resolution.
