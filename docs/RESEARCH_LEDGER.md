# Research Ledger

## 2026-08-19 - Founding the successor laboratory

### Prior pressure

The completed single-organism .NET lab reached a natural boundary after Protocol 20. It had accumulated enough evidence that standing, memory authority, influence, model complexity, relation habit, and consultation could develop under consequence without requiring every semantic role to be installed in advance.

Continuing to add controllers inside that organism risked recreating the earlier architectural problem: useful experimental scaffolding becoming declared anatomy.

### Pivot

The research center moves from development inside one bounded organism to development among bounded minds.

The new repository is intentionally separate. The old v1.0.0 source is treated as an experimental record and UX reference, not a codebase to keep extending.

### First question

The first higher-order pressure is memory inheritance.

A local system should be able to benefit from another system's experience. Yet WHUP and CPA both resist granting a local model access to a whole terrain it did not actually live. If second-hand compression enters with the same force as direct consequence, useful culture can become inherited distortion just as easily as inherited skill.

Protocol 01 therefore tests one small distinction: **availability across minds versus authority inside one mind**.

### Mechanism under test

A source publishes compact traces after they earn local standing. The receiver may admit those traces as foreign and provisional. Later receiver consequence determines whether their influence remains useful.

The control deliberately collapses that distinction by treating another mind's accumulated history as lived local evidence.

### Visualization pivot

The final old Desktop Lab had already addressed several graph costs, including compaction, display downsampling, cached drawing, and binary-search hover. Yet the WPF dispatcher still performed per-frame application into multiple visual models.

The new workbench stops treating frames as UI events. Frames become background telemetry. WPF samples a projected store at a human display cadence. Graph rebuild cadence adapts downward under rendering or projection pressure, and overly fine historical levels can retire from live UI memory. This shifts graphing from event-driven repaint toward snapshot-driven observation.
